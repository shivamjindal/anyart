Create a new branch. Make sure to follow the guidelines below for how to name the branch: 
- You must end the branch name with today's date in mmddyy format.
- For feature additions, prepend it with `feat/`. Example: `feat/add-dark-mode-032325`
- For bugs, prepend it with `bug/`. Example: `bug/fix-sort-by-price-110225`
- Be descriptive but keep the branch name short
