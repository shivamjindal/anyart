# AnyArt

An art gallery website showcasing artworks from the Art Institute of Chicago.

## Features

- Browse artworks from the Art Institute of Chicago collection
- Search for specific artworks
- Responsive design with modern UI
- Pagination for easy navigation


## Tech Stack

- Next.js 15
- React 18
- TypeScript
- Tailwind CSS
- ShadCN UI Components
- Jest & React Testing Library

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Testing

Run tests with:

```bash
npm test
```

## API

This project uses the [Art Institute of Chicago API](https://api.artic.edu/docs/).
